# YOLO Vision Workbench · UI 设计规范

> 版本：v0.1 · 2026-10
> 定位：**专业 AI 视觉工程平台**
> 参考气质：VS Code 的专业信息密度 · JetBrains 的软件质感 · Blender/Figma 的工作区布局
> 适用：后续所有页面/组件，P1-M02 起强制执行

---

## 1. 设计原则

| 原则 | 含义 | 反例（禁止） |
|------|------|----------------|
| 工作台而非后台 | 以「作业流」为中心，密度高、层级清晰 | 卡片堆叠 SaaS Dashboard |
| 专业克制 | 细线框、中性底、功能色点缀 | 大面积纯黑 / 荧光渐变 |
| 视觉优先级 | 图像/画布是主角，UI 退后 | UI 装饰抢过检测结果 |
| 可扫描 | 等宽数字、对齐网格、稳定布局抖动 | 按钮文字忽长忽短导致跳动 |
| 双主题 | 默认浅色工作台，暗色可选且完整 | 只有暗色或两套风格不一致 |

**一句话调性**：工程师白天开着干活的精密仪器面板，不是营销落地页。

### 2.3 功能色（检测结果 / 状态，双主题通用）

**状态色语义（固定，勿挪作装饰）**

| 状态 | 色 | 用于 |
|------|----|------|
| 就绪 / 成功 | 绿 | Backend 就绪、任务完成 |
| 进行中 | 蓝 | 推理中、进度条 |
| 警告 | 琥珀 | 重启中、参数钳制、跳过帧 |
| 失败 | 红 | 错误、连接失败 |
| 离线 / 未知 | 灰 | 未连接 |

**检测框默认色板（多模型）** — 按 model_id 轮转：

| # | Hex | 用途 |
|---|-----|------|
| 1 | `#2F6FED` | 模型 A |
| 2 | `#E85D4C` | 模型 B |
| 3 | `#1F9D66` | 模型 C |
| 4 | `#B45F06` | 模型 D |
| 5 | `#7C4DFF` | 模型 E |
| 6 | `#0E7C86` | 模型 F |

检测框在浅色底上描边 2px；标签底色用同色 92% 不透明，文字白色。中文标签用系统 UI 字体。

### 2.4 对比度

- 正文与背景对比度 ≥ **4.5:1**
- 大号/图标 ≥ 3:1
- 禁用态可降至 3:1，但必须有视觉区别（透明度/字重）

## 3. 字体与排版

### 3.1 字体栈

```css
--font-sans:
  "Inter", "Segoe UI", "PingFang SC", "Microsoft YaHei",
  "Noto Sans SC", system-ui, sans-serif;

--font-mono:
  "JetBrains Mono", "Cascadia Code", "Consolas",
  "SFMono-Regular", monospace;
```

- 中文优先系统黑体，保证清晰
- 数字/坐标/耗时/日志用 **等宽**
- 不使用衬线体、不使用圆角卡通字体

### 3.2 字阶（建议锁定，勿随意加大）

| Token | Size | Weight | 行高 | 用途 |
|-------|------|--------|------|------|
| `--text-xs` | 11px | 400/500 | 16 | 时间戳、标签、徽标 |
| `--text-sm` | 12px | 400/500 | 18 | 次要、表格、日志 |
| `--text-md` | 13px | 400/500 | 20 | **正文默认**、按钮 |
| `--text-lg` | 15px | 600 | 22 | 分区标题、面板标题 |
| `--text-xl` | 20px | 600 | 28 | 页面标题 |
| `--text-display` | 28px | 650 | 36 | 空状态大标题（慎用） |

**正文字号默认 13px**（工程工具密度），不要 14–16px 管理后台风。

### 3.3 字重

- 正文 400
- 强调/表头/选中 500–600
- 禁止整页 700+

### 3.4 数字

- 坐标、置信度、FPS、耗时：`font-variant-numeric: tabular-nums` 或等宽
- 置信度显示：`0.95` 两位小数或百分比 `95%`，全局统一为 **百分比整数** 在列表，详情两位小数

## 4. 布局系统

### 4.1 全局工作区（五区）

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏 52px  产品名 | 项目路径 | 主题切换 | Backend 状态 | 窗口控制   │
├────────┬────────────────────────────────────────┬───────────────┤
│ 左导航 │  中间工作区（工作台/列表/画布）          │ 右属性栏 288px │
│ 48px   │  flex:1                                │ （可折叠）     │
│ 图标栏 │                                        │ 参数/状态/属性 │
│ + 可选 │                                        │               │
│ 展开   │                                        │               │
│ 220px  │                                        │               │
├────────┴────────────────────────────────────────┴───────────────┤
│ 底部控制台 160px（可折叠）  日志 | 任务 | 设备                     │
└─────────────────────────────────────────────────────────────────┘
```

| 区 | 宽/高 | 行为 |
|----|-------|------|
| 顶栏 | 52px | 固定；左侧产品/项目，右侧状态与设置入口 |
| 左导航 | 48px 图标条；展开后 200–240px 标签 | 图标+中文 Tooltip；可展开为带文字列表 |
| 中间 | flex | 核心作业区；路由主内容 |
| 右栏 | 288px（±24） | 与当前上下文联动；可折叠为 0 |
| 控制台 | 默认收起 36px / 展开 160–280px | 日志/任务/输出 |

**布局参考**：Blender 左工具 + 中视图 + 右属性；Figma 左图层 + 中画布 + 右设计面板；VS Code 活动栏 + 编辑区 + 侧栏。

### 4.2 栅格与间距

**间距标度（8px 为主，4px 微调）**

| Token | px |
|-------|-----|
| `--space-1` | 4 |
| `--space-2` | 8 |
| `--space-3` | 12 |
| `--space-4` | 16 |
| `--space-5` | 20 |
| `--space-6` | 24 |
| `--space-8` | 32 |

- 面板内边距：`12px` 或 `16px`
- 列表行高：`32px`（紧凑）/ `36px`（默认）
- 控件高度：`28px`（紧凑按钮）/ `32px`（默认输入）

### 4.3 圆角与描边

| 元素 | 圆角 | 描边 |
|------|------|------|
| 面板 | 8px | 1px `--border` |
| 按钮 | 6px | 1px |
| 输入框 | 6px | 1px |
| 徽标/Tag | 999px 或 4px | 无/1px |
| 浮层 | 10px | 1px + `--shadow-md` |

避免大量 16–24px 圆角「消费级 App」感。

### 4.4 导航信息架构（左栏）

| 顺序 | 图标语义 | 中文名 | 路由建议 |
|------|----------|--------|----------|
| 1 | 屏/仪表 | **工作台** | `/workbench` |
| 2 | 文件夹 | **项目管理** | `/projects` |
| 3 | 立方体/模型 | **模型管理** | `/models` |
| 4 | 数据集 | **数据集** | `/datasets` |
| 5 | 播放/任务 | **推理任务** | `/tasks` |
| 6 | 芯片/设备 | **设备管理** | `/devices` |
| 7 | 齿轮 | **系统设置** | `/settings` |

底部可选：帮助、版本号、主题切换（若不放顶栏）。

## 5. 组件规范

### 5.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| Primary | 实心 `--accent`，白字 | 主操作（开始推理、打开项目） |
| Secondary | 白底 + 边框 | 次要（取消、刷新） |
| Ghost | 无边框，悬停有底 | 工具栏图标钮 |
| Danger | `--danger` 描边或实心 | 删除、强制停止 |

- 高度 28/32px；左右内边距 12px
- 图标钮 28×28，必须有 Tooltip（中文）
- 禁用：降透明度 + 禁止指针，保留文字可读

### 5.2 输入与滑条

- 输入框：单行高 32px，placeholder 用 `--text-muted`
- 数字框：右侧可上下箭头；单位后缀（如 `ms` `%`）
- 滑条：轨道 4px，拇指 14px；右侧显示数值（等宽）
- 下拉：选中态有对勾；支持搜索（模型/类别列表）

### 5.3 列表 / 表格

- 表头 12px 中性色，不加底色块以外的重装饰
- 行悬停 `--bg-hover`，选中 `--bg-active` + 左侧 2px accent 指示条
- 数字列右对齐；名称列左对齐截断加 Tooltip
- 空列表显示空状态插画/图标 + 一句话引导

### 5.4 徽标 / 状态点

- 状态点：8px 圆 + 状态色；旁边中文状态词（如「就绪」「重启中」）
- Tag：浅底 + 深字（用 soft 色阶），高度 18–20px

### 5.5 面板 / 分区

- 分区标题：`--text-lg` 或 13px/600 + 下边框或留白，不整条大色块
- 可折叠面板：箭头 + 标题 + 右侧辅助信息（如对象数）
- 属性面板字段：左标签 88px 右对齐，右控件 flex

### 5.6 空状态（必须设计，禁止空白 div）

| 场景 | 文案示例 | 视觉 |
|------|----------|------|
| 未打开项目 | 「打开或新建项目以开始」 | 线框图标 + 主按钮 |
| 无检测结果 | 「选择模型与图片，点击「开始推理」」 | 低对比插图 |
| 无模型 | 「在「模型管理」中添加模型配置」 | |
| 无任务 | 「暂无推理任务」 | |
| 无日志 | 「日志将显示在这里」 | |

### 5.7 加载与骨架

- 按钮加载：原位 spinner，宽度不跳变
- 面板加载：骨架块（灰 8% 透明度闪烁），**不用全屏转圈**
- 长任务：进度条 + 百分比 + 阶段文案（如「推理 3/10」）

### 5.8 模态与浮层

- 对话框宽：420 / 560 / 720
- 标题 + 正文 + 底右「取消 / 确定」（主按钮在右）
- 危险操作二次确认文案用中文、明确对象名

### 5.9 图标体系

- 统一线型图标（1.5–2px stroke），来源建议：Lucide / Tabler（开源）或自维护 SVG 集
- 尺寸：16px（工具栏）/ 20px（导航）
- **不用 emoji 代替图标**

## 6. 画布（检测工作台）规范

- 图像居中，等比缩放；底用 `--bg-canvas` + 可选棋盘格表示透明
- 检测框：叠加层，**不修改原图像素**
- 选中框：加发光或外描边；列表联动
- 隐藏框：不绘制（或 10% 透明虚线可选）
- 缩放：滚轮 / 快捷键；提供 适应窗口 / 100%
- 标签：`{id}:{类名}`，背景随框色，圆角 2px，11–12px

---

## 7. 动效

- 时长：120ms（小件）/ 180ms（面板）/ 220ms（对话框）
- 缓动：`cubic-bezier(.2,.8,.2,1)`
- **禁止**弹跳、大幅缩放、自动轮播装饰动画
- 减少动效偏好：`prefers-reduced-motion` 时降为淡入淡出

---

## 8. 响应式与窗口

- 最小窗口：**1100 × 700**（低于则提示可继续但布局紧凑）
- 右栏 &lt; 1280 宽时可自动折叠
- 外接大屏：工作区优先扩张，字号不随窗口放大

---

## 9. 文案与术语（配合中文化）

- 按钮用动词：「开始推理」「加载模型」「打开项目」
- 状态用短词：「就绪」「推理中」「失败」「已取消」
- 错误提示：**发生了什么 + 建议动作**（见 `LOCALIZATION.md`）
- 专有名词保留英文：YOLO、ONNX、TensorRT、RKNN、CUDA、FPS、WebSocket、RTSP、IoU、NMS 等

## 10. 与旧稿（P1-M01）差异

| 项 | M01 | 本规范 |
|----|-----|--------|
| 主题 | 暗色开发风 | **浅色默认** + 暗色可选 |

| 导航 | 顶栏操作 | **左侧工作台导航** |
