# UI 设计规范 v2 —「工坊 Instrument」

> 适用范围：YOLO Vision Workbench 桌面端（Electron + Vue3）
> 本档替代 `UI_DESIGN_SPEC.md` 中与视觉相关的部分；信息架构（IA）沿用原文档。

## 0. 一句话

**把界面当仪器，不当宣传页。** 视觉检测是长时间盯屏的重交互工作，设计目标是
"看得清、找得到、按得准"，而不是"第一眼惊艳"。所有装饰必须让位于数据。

三条硬规则：

1. **一个视图最多一个强调色实底按钮**（主操作）。其余动作用描边 / 幽灵按钮。
2. **数字必须等宽对齐**：延迟、置信度、坐标、帧号、尺寸一律 `tabular-nums`。
3. **动效只解释变化，不做表演**：≤280ms、无回弹过冲、无发光、无玻璃拟态。

## 1. 品牌标识

### 1.1 构成

标识由两个元素组成，位于 128 网格：

- **断角取景框**：左上 / 右下两段圆角折线（描边 10），四角断开留出负空间。
  它是"取景 / 检测框"，也是品牌记忆点。
- **Y**：琥珀渐变（#FFC247 → #F29311）粗笔画（描边 12），YOLO 的首字母，
  中心落于画布正中。两臂短、竖干长，保证读作 "Y" 而不是 "V"。

应用图标在标识外加深色磁贴（圆角 30，墨色渐变 #1B2532 → #0C121B + 1px 内高光）。

### 1.2 文件

| 文件 | 用途 |
|------|------|
| `desktop/build/icon.svg` | 图标矢量主稿（磁贴版） |
| `desktop/build/icon-{16..1024}.png` / `icon.ico` | 位图资产（由 `render_icon.py` 生成） |
| `desktop/build/brand/logo-mark.svg` | 磁贴版 Logo 矢量源稿 |
| `desktop/build/brand/logo-symbol.svg` / `desktop/build/brand/logo-symbol-dark.svg` | 无磁贴符号（浅底 / 深底） |
| `desktop/build/brand/logo-mono.svg` | 单色符号（`currentColor` 上色） |
| `desktop/build/brand/logo-wordmark.svg` / `desktop/build/brand/logo-wordmark-zh.svg` | 横版标识（英 / 中） |
| `desktop/build/brand/logo-splash.svg` | 启动动画（描边生长 + Y 落位） |
| `desktop/src/components/BrandMark.vue` | 应用内标识组件（`variant` / `animate`） |

### 1.3 使用规则

- **最小尺寸**：带磁贴 16px；无磁贴符号 20px；横版标识高度 ≥ 32px。
- **留白**：符号四周留出 ≥ 1/8 边长的净空，不与文字、线条相贴。
- **禁止**：改配色（琥珀是识别核心）、加投影 / 描边 / 光晕、把 Y 换成其他字母、
  在磁贴上叠加文字、拉伸变形。
- **单色场景**（丝印 / 烫印 / 水印）用 `desktop/build/brand/logo-mono.svg`，Y 与取景框同色。

## 2. 色彩

### 2.1 强调色 Signal Amber

| 令牌 | 浅色 | 深色 | 用途 |
|------|------|------|------|
| `--accent` | `#E8890C` | `#FFA928` | 主按钮、选中态、进度、检测命中 |
| `--accent-hover` | `#D2770A` | `#FFBC55` | 悬停 |
| `--accent-soft` | `#FDF0DC` | `#35260D` | 选中底、徽标底 |
| `--accent-contrast` | `#2A1A02` | `#241500` | 压在强调色上的文字 |
| `--accent-ink` | `#96560A` | `#FFC46B` | 浅底 / 深底上的强调色文字 |

琥珀取自车间安全色，语义就是"检测命中 / 现在做这个"。
**不得**用于大面积背景、渐变装饰、正文。

### 2.2 语义色

`--success` 绿 / `--warning` 深橙 / `--danger` 红 / `--info` 蓝，各配 `-soft` 底色。
状态胶囊 = 语义色文字 + soft 底 + 32% 语义色描边，三件套固定搭配。

### 2.3 中性面

浅色：面板纯白 `#FFFFFF`、工作台 `#E8EBEF`、画布 `#DFE3E9`、发丝线 `#E2E5EA`；
深色：面板 `#191F27`、工作台 `#0D1116`、画布 `#0A0D11`、发丝线 `#262D37`。

层次靠 **1px 发丝线 + 表面明度差**，不用投影堆叠。投影只给浮层
（`--shadow-md` 对话框、`--shadow-lg` 弹出菜单）。

### 2.4 对比度

正文 / 面板 ≥ 4.5:1，大字与图形 ≥ 3:1。
浅色正文 `#161C25`、次要 `#46515F`、弱化 `#737E8C`（仅用于 11px 以上的辅助信息）。

## 3. 排版

- 中文：系统黑体栈（PingFang SC / HarmonyOS Sans SC / 微软雅黑 / 思源黑体）。
- 西文与数字：Inter / Segoe UI；等宽 JetBrains Mono / Cascadia Mono。
- 不引入网络字体（桌面端离线可用性优先）。

| 层级 | 字号 / 字重 | 用途 |
|------|-------------|------|
| display | 26 / 680 | 空状态大标题 |
| title | 19 / 650 | 页面标题（`-0.012em` 字距） |
| section | 15 / 650 | 面板 / 分组标题 |
| body | 13 / 400 | 正文、表单 |
| caption | 12 / 400 | 辅助说明 |
| micro | 10 / 650 `+0.08em` 大写 | 分组微标签（`Parameters · 参数`） |
| mono | 12 / 400 tabular | 数字与代码 |

## 4. 布局（五区）

```
┌──────────────────────────────────────────────┐
│ 顶栏：品牌 · 模式分段 · 项目 · 状态 · 操作      │ 50px
├────┬─────────────────────────────┬───────────┤
│ 左 │                             │ 右属性栏   │
│ 导 │        主工作区（画布）        │  288px    │
│ 航 │                             │           │
│64px│                             │           │
├────┴─────────────────────────────┴───────────┤
│ 底部控制台（可折叠）                           │ ≥36px
└──────────────────────────────────────────────┘
```

- **顶栏**：左品牌位（标识 + 名称 + 细线 + 标语），中部分段控件切模式，
  右侧状态胶囊 + 等宽延迟 + 主题切换 + 重启。操作与状态分居两侧，不混排。
- **左导航**：图标 + 微标签，选中态 = 琥珀浅底 + `--accent-ink` 文字（不做左侧色条）。
- **右属性栏**：`.aside-section` 卡片纵向堆叠，标题用 micro 标签。
- **控制台**：日志行等宽三列（时间 / 级别 / 内容），级别着色克制。

## 5. 控件

| 控件 | 规格 |
|------|------|
| 主按钮 | 高 26–28px、圆角 8、琥珀底 + `--accent-contrast` 文字、1px 内高光 |
| 次按钮 | 白底 + 发丝描边；悬停换 `--bg-hover` |
| 幽灵按钮 | 无边框，仅悬停出底色 |
| 分段控件 | `--bg-inset` 容器 + 白色滑块 + `--shadow-sm`，滑块 240ms 跟随 |
| 状态胶囊 | 高 24、圆角 999、软底软边、6px 圆点 |
| 输入 / 下拉 | 高 28、圆角 8、发丝描边，聚焦 `--focus-ring`（2px 面板色 + 4px 琥珀） |
| 表格 | 表头 micro 标签大写；行悬停 `--bg-hover`；发丝行分隔 |
| 滑块 | 4px 轨 + 琥珀填充 + 白色 12px 圆钮 |

**检测框（画布）**：2–3px 描边、圆角 4–6、标签贴框上沿；
框线外侧再描一圈 7px、55% 黑色光晕，保证框线压在任何亮度的图像上都可读；
标签底色 = 类别色，**文字颜色按底色明度自动取深 / 浅**（对比度 ≥ 4.5:1）；
标签格式 `类别名 + 等宽置信度`。密集小目标时标签缩到 10px 或折叠为计数。

## 6. 动效

| 令牌 | 值 | 用途 |
|------|----|------|
| `--dur-fast` | 120ms | hover / 按下 / 颜色变化 |
| `--dur-mid` | 180ms | 页面进场（fade + 4px 上移） |
| `--dur-slow` | 280ms | 浮层、控制台展开 |
| `--ease` | `cubic-bezier(.22,1,.36,1)` | 进出场 |
| `--ease-inout` | `cubic-bezier(.65,0,.35,1)` | 布局变化 |
| `--spring` | `cubic-bezier(.32,.72,0,1)` | 滑块 / 跟手（无过冲） |

- 列表错峰 24ms 递增，最多 10 项。
- 路由切换用 View Transitions（`withViewTransition`），180ms。
- 启动动画：取景框两段描边生长（550ms，第二段延迟 160ms），Y 缩放落位（500ms，延迟 420ms）。
- **禁止**：弹跳过冲、辉光、循环装饰动画、超过 300ms 的过渡。
- `prefers-reduced-motion: reduce` 时全部动画与过渡退化为 0 时长。

---

## 7. 深色主题

同一套层级关系，只换表面与文字色：
中性面整体压暗一档（面板 `#191F27`），强调色提亮（`#FFA928`）保持同等视觉权重，
语义色全部提亮以保住对比度。画布区比工作台更暗，让图像本身成为最亮的元素。
